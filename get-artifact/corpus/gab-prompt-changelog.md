# Draft Page Changelog

## Status

Active

## Objective

Summarize what changed in a page revision for the page's watchers.

## Input

The previous and new revision of the page.

## Instructions

Describe content changes a reader would care about: added sections, removed guidance, changed recommendations. Ignore formatting-only edits.

## Output

Two to four bullets, each naming the section that changed.

## Constraints

Never describe an edit that is not present in the diff.
