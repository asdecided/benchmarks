# Full-Text Search

## Status

Accepted

## Problem

Readers navigate by folder tree today, and anything more than two levels deep is effectively invisible.

## Requirements

- [REQ-001] Readers MUST be able to search all pages they can read, by phrase and by word.
- [REQ-002] Results MUST show a highlighted snippet around the match.
- [REQ-003] The index MUST reflect a published edit within one minute.

## Success Metrics

- Search-originated page views exceed tree-originated views within a quarter.
