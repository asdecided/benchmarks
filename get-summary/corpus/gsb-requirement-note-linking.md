# Note Linking

## Status

Accepted

## Problem

Notes accumulate but never connect, so recall depends on remembering titles.

## Requirements

- [REQ-001] Typing a link trigger MUST offer title completion across all notes.
- [REQ-002] Every link MUST be traversable in both directions.
- [REQ-003] Renaming a note MUST update every link to it.

## Success Metrics

- Half of active notes carry at least one link after two months of use.
