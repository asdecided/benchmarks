Coding agents increasingly operate inside repositories carrying years of recorded
decisions---architecture decision records, standards, and deprecations---that
constrain what a correct change is. A common objection holds that long-context
frontier models simply absorb these decisions, so a dedicated grounding layer adds
no durable value. We test that objection directly with \benchname, a benchmark for
\emph{decision adherence} built from real, public, reproducible corpora whose
supersession is stated by the artifacts themselves (Python PEPs, IETF RFCs, W3C
recommendations). Each scenario asks whether an agent follows the live
\emph{governing} decision and drops the one it supersedes. All arms feed one
held-constant answering model behind one fixed scaffold and receive a single,
symmetric opportunity to populate the context window, differing \emph{only} in how
grounding is selected and assembled: full context dump, naive RAG, and a
deterministic, supersession-aware layer. Scoring is deterministic and
structural---no embeddings, no LLM judge---over decision adherence,
governing-decision recall, and false-permit/false-prohibit rates. The headline
artifact is an adherence-versus-corpus-size curve exposing where strategies diverge
as the governing decision is buried among real distractors, reported alongside
